# AI-Powered Drink Recommendation & Favorite Tracker

A Python desktop prototype that combines AI-powered drink recommendations with a personal drink database.

## Features

- Generates drink recipes based on flavor preferences and available ingredients using the OpenAI API.
- Stores drink names, ingredients, favorites, and categories in SQLite.
- Allows users to browse drinks, mark favorites, and assign categories.
- Provides AI-generated ratings and suggestions for custom recipes.
- Includes a Tkinter menu interface for accessing application features.

## Technologies Used

- **Python** — Application logic
- **SQLite** — Drink database
- **Tkinter** — Desktop menu interface
- **OpenAI API** — Recipe recommendations and feedback

## Limitations

- User input and AI responses are handled through the terminal.
- Weather and nearby coffee shop suggestions are generated without live weather or map integrations.
